# Tasca S1.04 - POO

Descripció: Exercicis per practicar la programació orientada a objectes (POO) en PHP, treballant classes, objectes, herència, mètodes i propietats.

## Tecnologies

* PHP
* XAMPP
* Visual Studio Code

## Instal·lació

1. Clonar el repositori:

```text
git clone https://github.com/jordiartigues/Tasca-S1.04.git
```

2. Obrir el projecte amb Visual Studio Code.

3. Per executar els exercicis des de la terminal, entrar a la carpeta del projecte:

```text
cd Tasca-S1.04
```

4. Entrar a la carpeta dels exercicis:

```text
cd "Nivel I"
```

5. Executar el primer exercici:

```text
php exercici1.php
```

6. Per executar el segon exercici, entrar a la seva carpeta:

```text
cd exercici2
```

I executar:

```text
php index.php
```

7. Per executar l'exercici de `Nivel II`:

```text
cd ..\Nivel II\exercici1
```

I executar:

```text
php index.php
```
